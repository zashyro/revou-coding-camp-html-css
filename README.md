# To-Do Life Dashboard

A simple life dashboard web app built as part of the RevoU Coding Camp (18 May 2026).

## Features

- **Greeting** — shows current time, date, and a greeting based on time of day
- **Custom Name** — personalize the greeting with your name (saved to Local Storage)
- **Focus Timer** — 25-minute Pomodoro countdown with Start, Stop, and Reset
- **To-Do List** — add, edit, complete, delete, and sort tasks (saved to Local Storage)
- **Quick Links** — save and open your favorite websites (saved to Local Storage)
- **Light / Dark Mode** — toggle between themes, preference is saved

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript (no frameworks)
- Browser Local Storage API

## How to Run

Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). No setup required.
